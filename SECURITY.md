# Security Policy

## Scope

This project is a small local inspection utility. It reads matching files under the expected Claude Code bundle directory and prints selected strings.

## Reporting an issue

If you find a security-relevant issue, please avoid publishing sensitive machine-specific output. Open a private report through the hosting platform's available security-reporting process if one is enabled; otherwise contact the repository maintainer privately.

## Safe use

- Review the script before executing it.
- Do not run modified copies from untrusted sources.
- Check terminal output for private paths before sharing it.
- This utility does not verify runtime behavior or establish whether a matching string is used.
